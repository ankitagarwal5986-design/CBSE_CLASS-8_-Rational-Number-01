⚡ Foundational Principles of Rational Numbers

A number that can be expressed in the form \(\frac{a}{b}\), where \(a\) and \(b\) are integers and \(b \ne 0\), is called a rational number. Division by zero is undefined.

1. Standard Form Criteria

A rational number \(\frac{a}{b}\) is in standard form if and only if:

1. The denominator \(b\) is positive (\(b > 0\)).

2. Numerator \(a\) and denominator \(b\) are co-prime: \(\text{HCF}(|a|, |b|) = 1\).

2. Number Line Ordering & Cross Multiplication

Numbers to the right on a number line are strictly greater than numbers to the left.

For \(\frac{a}{b}\) and \(\frac{c}{d}\) with positive denominators \(b, d > 0\):

• If \(a \times d > b \times c \implies \frac{a}{b} > \frac{c}{d}\).

• If \(a \times d = b \times c \implies \frac{a}{b} = \frac{c}{d}\).

3. Absolute Value of Rational Numbers

The absolute value represents the non-negative distance from zero on the number line:

\[\left|\frac{a}{b}\right| = \left|-\frac{a}{b}\right| = \frac{|a|}{|b|}\]

For example, \(\left|-\frac{3}{4}\right| = \left|\frac{3}{4}\right| = \frac{3}{4}\).

4. Properties of Addition

  • Closure: \(\frac{a}{b} + \frac{c}{d}\) is always a rational number.
  • Commutative: \(\frac{a}{b} + \frac{c}{d} = \frac{c}{d} + \frac{a}{b}\).
  • Associative: \((\frac{a}{b} + \frac{c}{d}) + \frac{e}{f} = \frac{a}{b} + (\frac{c}{d} + \frac{e}{f})\).
  • Additive Identity: \(0\) is the additive identity: \(\frac{a}{b} + 0 = \frac{a}{b}\).
  • Additive Inverse: \(-\frac{a}{b}\) is the additive inverse: \(\frac{a}{b} + (-\frac{a}{b}) = 0\).
